Features

Everything You Need.

No browser extensions, no shady websites. A clean Python script that just works.

Highest Quality Always
Automatically picks the best video and audio streams and merges them into a single clean MP4 using ffmpeg.
Full Playlist Support
Download entire playlists at once. Videos are numbered in playlist order and saved in a named subfolder.
Pre-flight Checks
Verifies yt-dlp and ffmpeg are installed before running — no silent failures, no mystery errors.
Zero Config Python
Python 3.8+, one requirements.txt, one script. Run it, paste a URL, done. VS Code task included.
Organized Output
All files go to your ~/Youtube folder. Playlists get their own named subfolder, numbered correctly.
Clear Error Messages
Invalid URLs, missing ffmpeg, private videos — every failure gives you a plain English explanation.
How It Works

Three Steps. Done.

From zero to downloaded video in under two minutes.

1
Clone & Install
Clone the repo and run pip install -r requirements.txt. That's the only dependency.
2
Run the Script
Launch with python youtube_downloader.py from terminal or VS Code task runner.
3
Paste & Download
Paste any YouTube URL when prompted. The script picks the best quality, merges streams, and saves your file.
